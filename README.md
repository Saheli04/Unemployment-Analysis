# 📊 Unemployment Analysis with Python

An interactive data analytics project that explores unemployment trends in India using Python, Pandas, Plotly, and Streamlit. The project focuses on regional differences, rural vs. urban unemployment, labour participation, and changes observed during the March–June 2020 COVID-19 period.

## 🚀 Project Overview

Understanding unemployment trends helps identify differences across regions and areas and provides insights into labour market patterns.

This project transforms raw unemployment data into a cleaned dataset, exploratory visualizations, statistical summaries, and an interactive dashboard where users can filter and explore the data.



## 🎯 Objectives

* Analyze unemployment trends across Indian regions.
* Compare unemployment rates in rural and urban areas.
* Identify regions with relatively high and low average unemployment rates.
* Explore relationships between unemployment, employment estimates, and labour force participation.
* Compare observations before March 2020 with those from March–June 2020.
* Build an interactive dashboard for data exploration and visualization.

## 📈 Key Features

### 1. Data Cleaning and Preprocessing

* Loads the unemployment dataset.
* Removes completely blank rows.
* Handles date and numeric data types.
* Removes records with missing values in essential analysis fields.
* Creates a year-month field for time-based analysis.

### 2. Exploratory Data Analysis

* Examines unemployment patterns over time.
* Compares unemployment across regions.
* Analyzes rural and urban differences.
* Studies labour participation and employment estimates.

### 3. Interactive Streamlit Dashboard

The dashboard provides:

* **KPI cards:** Average unemployment, median unemployment, labour participation, and regions covered.
* **Time-series analysis:** Monthly unemployment trends.
* **Regional comparison:** Average unemployment by region.
* **Rural vs. urban analysis:** Comparison of unemployment rates across areas.
* **Distribution analysis:** Histogram and box plot of observed unemployment rates.
* **Relationship analysis:** Unemployment versus labour participation, with estimated employment represented by marker size.
* **Period comparison:** Observations before March 2020 versus March–June 2020.
* **Interactive filters:** Select regions, areas, and date ranges.
* **CSV export:** Download the currently filtered dataset.

## 📊 Dataset

The project uses the *Unemployment in India* dataset.

The analysis uses fields such as:

* `Region`
* `Date`
* `Frequency`
* `Estimated Unemployment Rate (%)`
* `Estimated Employed`
* `Estimated Labour Participation Rate (%)`
* `Area`

The dataset covers observations from May 2019 to June 2020 after preprocessing in the current analysis.

**Dataset source:**  (https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)

## 💻 Installation and Setup

### Step 1: Clone the repository

```bash
git clone (https://github.com/Saheli04/Unemployment-Analysis)
```



### Step 2: Open the project folder

```bash
cd Unemployment_Analysis
```

### Step 3: Create a virtual environment (recommended)

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### Step 4: Install dependencies

```bash
pip install -r requirements.txt
```

If you do not yet have a complete `requirements.txt`, install the required packages with:

```bash
pip install pandas numpy matplotlib seaborn plotly streamlit
```

### Step 5: Run the analysis

```bash
python main.py
```

This runs the analysis and generates the cleaned data and outputs configured in the script.

### Step 6: Launch the interactive dashboard

```bash
streamlit run dashboard.py
```

Open the local URL displayed in the terminal, usually:

```text
http://localhost:8501
```

Ensure that `outputs/cleaned_unemployment_data.csv` exists before launching the dashboard.

## ⚠️ Important Notes

* Dashboard metrics are calculated from the selected region-area observations.
* The displayed averages are **unweighted averages**, not official national unemployment estimates.
* Differences between the pre-COVID and COVID-period observations do not establish that COVID-19 alone caused the changes.
* Results depend on the dataset, its coverage, and the preprocessing decisions.
